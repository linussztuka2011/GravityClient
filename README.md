# GravityClient

A project built and vibecoded with Antigravity.

## Sync & Dev Workflow

To continue coding on another computer:

1. **On this computer** (after finishing a session):
   ```bash
   git add .
   git commit -m "Vibe updates"
   git push
   ```

2. **On the other computer** (first time setup):
   ```bash
   git clone https://github.com/linussztuka2011/GravityClient.git
   ```

3. **On the other computer** (before starting to code):
   ```bash
   git pull
   ```
